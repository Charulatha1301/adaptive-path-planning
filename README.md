
# Adaptive Path Planning and Collision Avoidance

## Autonomous Vehicle Simulation for Unstructured Indian Roads

This project is a software simulation of an autonomous vehicle operating on unstructured Indian roads.

### Features

- Adaptive path planning
- Obstacle detection
- Collision risk detection
- Safe lane selection
- Real-time replanning
- Collision avoidance
- Return to original lane after passing an obstacle

### Scenarios

- Village Road
- Urban Intersection
- Highway Merge
- Market Area
- Sudden Cattle Crossing

### Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Type

Software Simulation Prototype
